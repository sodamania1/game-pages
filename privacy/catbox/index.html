2. 기기에 저장하는 정보와 목적

회원가입 없이 플레이할 수 있습니다. 이어하기, 설정 유지, 발견한 해답 표시 및 플레이 테스트 기록을 위해 아래 정보를 사용자 기기에 저장합니다.

  • 완료·해금한 스테이지, 발견한 배치, 현재 스테이지와 고양이 배치, 되돌리기 기록
  • 소리·진동·언어 설정
  • 플레이 시각·시간, 스테이지 시작·종료·완료, 이동·되돌리기·힌트·잘못된 배치 기록, 로컬 테스트·시도 식별값

식별값은 게임에서 생성하며 광고 ID나 계정 ID가 아닙니다. 플레이 이벤트는 최근 최대 3,000개까지 보관합니다. Android에서는 앱 저장공간에, 웹에서는 해당 사이트의 브라우저 저장공간에 기록합니다.

3. 수집·전송·공유

현재 게임에는 계정 서버, 광고 SDK, 외부 분석 SDK, 자동 오류 보고 또는 클라우드 저장 기능이 없습니다. 게임은 위 로컬 기록을 개발자 서버로 자동 전송하거나 판매하지 않습니다. 연락처·정확한 위치·카메라·마이크·광고 식별자를 게임 기능으로 수집하지 않습니다.

Android 앱은 폰트를 포함하고 있어 게임과 안내 문서를 오프라인으로 이용할 수 있습니다. 웹 게임은 Google Fonts에서 폰트를 불러오므로 접속 과정에서 IP 주소 등 네트워크 요청 정보가 Google에 전달될 수 있습니다. 웹 배포 플랫폼(예: itch.io)과 앱 스토어가 별도로 처리하는 접속·설치 정보에는 해당 서비스의 개인정보처리방침이 적용됩니다.

4. 사용자가 직접 내보내는 기록

웹 버전의 테스트 기록 내보내기를 선택하면 완료·발견 기록과 플레이 이벤트가 JSON 파일로 기기에 저장됩니다. 자동 업로드는 하지 않습니다. 해당 파일을 다른 사람에게 보내는 것은 사용자가 별도로 선택하는 행동입니다. Android 앱에서는 테스트 기록 메뉴를 표시하지 않습니다.

5. 보관 기간과 삭제

진행도와 설정은 앱 또는 브라우저의 저장 데이터를 삭제할 때까지 기기에 남습니다. Android 설정에서 이 앱의 저장공간 데이터를 삭제하거나 앱을 제거하면 로컬 게임 데이터를 삭제할 수 있습니다. 웹에서는 브라우저 설정에서 해당 사이트의 데이터를 삭제할 수 있습니다. 삭제한 진행도는 개발자 서버에서 복구할 수 없습니다.

이미 내보낸 JSON 파일은 사용자가 파일 앱에서 따로 삭제해야 합니다. 웹의 ‘새 참가자로 시작’은 진행도를 초기화하지만 이전 테스트 이벤트를 남기므로 전체 기록 삭제 기능이 아닙니다.

6. 아동 이용

연령과 관계없이 동일한 로컬 저장 방식이 적용됩니다. 현재 게임에는 이름·연락처를 입력하는 가입 화면이나 채팅 기능이 없습니다.
