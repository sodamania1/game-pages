Cats Are Liquid Privacy Policy

Written: September 30, 2026 · Effective date: November 1, 2026

1. Scope and operator

This policy applies to the current versions of the Cats Are Liquid Android app and web game. Developer name: sodamania1. Privacy contact email: sodamania1support@gmail.com.

2. Information stored on your device and its purpose

You can play without creating an account. We store the following information on your device to resume your game, remember settings, display discovered solutions, and keep playtest records.

  • Completed and unlocked boxes, discovered arrangements, the current box and cat positions, and undo history
  • Sound, vibration, and language settings
  • Play dates and durations; box start, exit, and completion events; moves, undo actions, hints, and invalid placements; local playtest and attempt identifiers

The game generates these identifiers; they are not advertising IDs or account IDs. Up to the latest 3,000 play events are retained. Records are stored in app storage on Android and in browser storage for the site on the web.

3. Collection, transmission, and sharing

The current game has no account server, advertising SDK, external analytics SDK, automatic error reporting, or cloud saves. The game does not automatically send the local records described above to a developer server or sell them. Game features do not collect contacts, precise location, camera or microphone data, or advertising identifiers.

The Android app includes its fonts, so the game and information documents work offline. The web game loads fonts from Google Fonts, which may send network request information such as your IP address to Google. Connection and installation information separately processed by web distribution platforms (such as itch.io) and app stores is covered by those services’ privacy policies.

4. Records you export yourself

If you export playtest records in the web version, completion records, discoveries, and play events are saved to a JSON file on your device. The file is not automatically uploaded. Sharing it with someone else is a separate action you choose. The Android app does not display the playtest records menu.

5. Retention and deletion

Progress and settings remain on your device until you delete the app or browser storage data. On Android, you can delete local game data by clearing this app’s storage in Android settings or uninstalling the app. On the web, you can delete this site’s data in browser settings. Deleted progress cannot be recovered from a developer server.

You must delete previously exported JSON files separately using your file manager. “Start a new playtest” on the web resets progress but retains earlier test events; it does not delete all records.

6. Children’s use

The same local storage behavior applies regardless of age. The current game has no registration screen asking for names or contact information, and no chat feature.

7. Changes and contact

If features such as advertising, analytics, or accounts change how information is processed, we will update this policy and any required notices before those changes take effect. For privacy-related inquiries, contact the developer, sodamania1, at sodamania1support@gmail.com. Information provided in an inquiry will be used only to review and respond to that inquiry.
