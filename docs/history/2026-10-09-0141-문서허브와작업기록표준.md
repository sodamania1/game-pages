# 문서 허브 구축·정책 언어·pull 확인과 작업 기록 표준 적용

- 날짜·시각: 2026-10-09 01:41
- 시간대: Asia/Seoul (UTC+09:00)
- 기록 범위: 이 대화에서 확인 가능한 2026-09-30 이후 요청과 작업을 이번 요청에 따라 요약한 소급 기록. 개별 과거 작업 시각은 추측하지 않았다.

## 요청 요약

- 여러 게임의 외부 공개 문서를 관리하는 `game-pages` GitHub Pages 정적 저장소를 구축하고 검증·배포·가능하면 커밋할 것을 요청했다.
- 후속으로 GitHub에 올렸는지 확인을 요청하고, 개인정보처리방침을 언어별로 작성해야 하는지 질문했다.
- pull로 들어온 변경 내용을 확인할 것을 요청했다.
- `project-standards` 작업 기록 표준을 이 프로젝트에 적용하고 이 대화를 표준에 맞게 요약할 것을 요청했다.

## 결정과 이유

- HTML/CSS와 `.nojekyll`로 빌드 없는 문서 허브를 만들었다. 게임 코드·프레임워크·외부 UI 라이브러리·추적 기능은 추가하지 않았다.
- 빈 로컬 디렉터리에서 시작했지만 인증 계정의 기존 공개 저장소를 발견해 복제하고 이력을 보존했다. 새 저장소 생성 대신 기존 `sodamania1/game-pages`를 사용했다.
- 개인정보 처리 사실과 공개 연락처를 확인할 수 없었던 아홉 게임은 TODO 초안으로 유지했다. 완성된 법률 문구나 임의의 이메일·회사명을 만들지 않았다.
- `.html` 없는 디렉터리 URL과 일반 페이지의 상대 경로를 채택했다. 404는 잘못된 경로의 깊이에 대응하도록 `/game-pages/` 기준 링크를 사용했다.
- 언어별 작성 질문에는 Google Play 일반 정책에서 모든 지원 언어별 작성 의무를 확인하지 못했다고 설명하고 한국어·영어 제공을 제안했다. 출시 국가별 요건까지 영어 하나로 충족한다고 보장하지 않았다. 이 질문만으로 사이트를 수정하지 않았다.
- 이후 pull된 Catbox 변경은 한국어 기본 페이지와 영어 하위 페이지로 구성되어 있었다. 한 페이지에 두 언어를 함께 넣는 앞선 제안은 확정 구현으로 채택되지 않았다.
- `work-history` 1.0은 중앙 원문 그대로 복사했다. 현행 계약·현재 인계·과거 기록·색인을 분리하고 Godot 도구 표준은 정적 사이트에 적용하지 않았다.
- 기록 규칙 자체는 커밋·푸시 권한을 부여하지 않는다. 이번 문서 작업에서는 커밋·푸시하지 않았다.

## 변경·검증

- 최초 구축: 루트 HTML 수정과 게임별 정책 9개·Privacy 목록·Support·Terms·404·CSS·README·`.gitignore`·`.nojekyll` 추가. 커밋 `cb7f2d4`를 기존 `main`에 푸시했다. 기존 Pages `main / (root)` 설정을 사용했다.
- 당시 검증: 로컬 HTTP에서 HTML 14개와 링크·CSS 요청 126건 정상. 기본 HTML 구조·viewport·탐색 확인. 모바일 375px에서 가로 넘침 없음. 공개 HTML·CSS의 커밋 일치와 깊은 잘못된 URL의 사용자 정의 404, Pages 배포 완료를 확인했다.
- GitHub 업로드 후속 확인: 로컬과 원격 `main`의 `cb7f2d4` 일치, 미커밋·미푸시 변경 없음 확인.
- pull 검토: `4862c70`(Publish Catbox privacy policies in Korean and English)이 fast-forward로 들어온 것을 확인했다. 변경은 README·CSS·메인·Privacy 목록·Catbox 두 정책의 6개 파일이었다. 한국어 줄바꿈, 언어 전환, canonical/hreflang, 원본 출처가 추가됐다.
- pull 검증: HTML 16개와 내부 링크·CSS 경로 158건, HTML 중첩 정상. 두 정책 본문은 Catbox 원본 커밋 `a0f036bea07f9514e6eeb3169cd6d3e649e664bd`의 `legal/privacy.html`과 `legal/privacy.en.html`에 일치했다. 작성일 2026-09-30·시행일 2026-11-01을 확인했다.
- 이번 변경: 루트 AGENTS, 표준 배포본, 사이트 계약, handoff, 이 기록과 INDEX 추가. README에 작업 문서 구조·시작 안내 추가.
- 이번 검증: 표준 원문과 배포본의 바이트 일치, 문서 상대 링크, 템플릿 필수 항목, 파일명과 기록 시간대, diff 공백 오류를 확인했다.
- 미수행 검증·이유: 실제 게임 구현의 개인정보 처리와 법적 충족 여부는 게임 조사·법적 검토를 수행하지 않아 보장하지 않는다. 이번에는 운영 문서만 추가했으므로 사이트 HTTP·모바일·현재 원격 및 Pages 상태를 재검증하지 않았다.
